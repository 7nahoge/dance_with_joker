# danSiNg with the joker ～ジョーカーと秘密のワルツ～

白髪のジョーカーと踊る、2レーンのブラウザー用リズムゲーム。assets/joker_music_s.wav を加工せず、そのまま使用します。外部ライブラリ・API・バックエンドは不要です。

## 起動と操作

このフォルダーで `python -m http.server 8000` を実行し、http://localhost:8000 を開いてください。Live Serverなどの静的HTTPサーバーも利用できます。file:// では音楽を読み込めません。

- 左は F、右は J。画面下の左右ボタンはタッチ・クリックにも対応。
- カードの中心が判定ラインに重なったら入力します。
- Perfect：±80ms、100点。Good：±160ms、60点。Miss：160ms超過。
- 一時停止ボタンまたは Esc で中断。タブを離れたときも自動停止します。
- 右上で音量・ミュートを変更できます。

## 音楽と難易度

- 各回はBGMを1回だけ再生。満点の60％以上で合格し、結果画面から次のレベルへ進みます。不合格なら同じレベルを再挑戦します。タイトルへ戻るとレベル1に戻ります。
- レベル1は表拍の一部、レベル2は全表拍、レベル3は裏拍の半分を追加、レベル4は全譜面。レベル5以降はGood判定幅が毎回5msずつ縮み、最小±90msになります。Perfect判定幅はその半分です。

- テンポは音源本来の150 BPM（等速再生）。6拍、2.4秒のカウントインのあと、音源の最後まで約68.1秒間再生します。カード枚数・配置・レベルごとの判定幅・合格条件は維持します。
- 全、満点22600点。各フレーズは32→34→36→38→28→28→30枚。最後の3フレーズは6枚のうち最後の2枚を抜き、4枚ごとに休みを入れます。
- 元音源の拍を基準に表拍と8分音符の裏拍を配置。裏拍は各フレーズ8→10→12→14→11→12→14枚、計です。「1と2と3と」の「と」にもカードが来ます。
- 最短間隔はプレイ中約200ms。同じレーンの判定範囲は重ならず、同時押し・同一レーンの3連続はありません。速い部分では左右交互、遅い部分には同じ側の2連打を含みます。
- 各フレーズは3拍子の8小節で繰り返し、境界でも拍の間隔を維持します。

## 音源の生成と構成

- source/joker_movie.wav：再生成用の元音源。ゲームからは直接読みません。
- js/build-music.cjs：元音源の0.11〜9.11秒をメロディーの順序・速度を保って使用。末尾だけに減衰する残響を加え、足りない0.6秒を補って8小節（150 BPMの24拍・9.6秒）にします。小節の複製や短い音片の反復は使いません。つなぎ目の前後5msはフェードし、クリック音を抑えます。
- assets/joker_music_s.wav：既存の音源をそのまま読み込みます。等速で一度だけ、フェードや残響を追加せず最後まで再生します。
- js/music-chart.js：音源の拍と各フレーズの開始時刻に同期した譜面。元音源上の繰り返し境界は9.6・19.2・28.8・38.4・48・57.6秒です。
- js/analyze-melody.cjs：再生成時の旋律解析。解析結果は参考情報として保持しますが、現在のカード配置は表拍と裏拍を使用します。
- js/game.js：WAV読み込み、再生予約、判定、描画。AudioContext.currentTimeを音楽・判定・終了時刻に共用します。中断はsuspend/resumeで音楽ごと停止し、再開時の同期を保ちます。
- index.html / style.css：画面構成と表示。画像・動画が読めないときも仮表示で続行できます。動画はミュート再生で、音楽の開始から6拍後（2.4秒後）に先頭から動き始めます。一時停止・再開は音楽と連動します。

参考音源の生成：`node js/build-music.cjs`（joker_music.generated.wav と music-chart.generated.js に出力し、使用中の音源・譜面を上書きしません）

自動検証：`node js/verify.cjs`

Node.js標準機能のみを使用します。使用中の joker_music_s.wav は再生成しません。

## 検証

音源の長さ、全50ms区間に意図しない無音がないこと、クリッピングがないこと、繰り返し境界のゼロ振幅を数値検証しています。表拍・裏拍の位置、各フレーズの枚数、同一レーンの判定間隔も検証します。

DOMとWeb Audioのモックを使い、音源読み込み・キャッシュ・失敗時の復帰、再生時刻、中断・再開、リトライ、最後までの進行、判定境界、重複得点防止、キーリピート無視、タブ非表示時の中断、画像・動画欠落、全Perfectで22600点を検証しています。

実機での試聴、スマートフォンでの操作感、Bluetooth機器などの出力遅延は未検証です。出力遅延補正は実装していません。
