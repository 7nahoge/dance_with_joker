# danSiNg with the joker ～ジョーカーと秘密のワルツ～

ジョーカーと踊る、2レーンのブラウザー用リズムゲーム。外部ライブラリ・API・バックエンドは不要です。

## 起動と操作

このフォルダーで `python -m http.server 8000` を実行し、http://localhost:8000 を開いてください。静的HTTPサーバーが必要です。file:// では音楽を読み込めません。

- 左は F、右は J。画面下の左右ボタンはタッチ・クリックにも対応します。
- カードの中心が金色の判定ラインに重なったら入力します。
- Perfectは100点、Goodは60点。Missでコンボが途切れますが、最後まで遊べます。
- 一時停止ボタンまたは Esc で中断。タブを離れたときも自動停止します。
- 右上で音量・ミュートを変更できます。

## 音楽と難易度

6拍（2.4秒）のカウント後、assets/joker_music_s.wav を等速で最後まで1回再生します。音源は約9.5秒で、テンポは150 BPMの3拍子です。動画はカウント終了後に先頭から動き始め、一時停止・再開は音楽と連動します。

カード枚数はレベル1で19枚、レベル2で22枚、レベル3で25枚、レベル4〜10で28枚。休みの小節にも頭の1枚を置き、残りの2拍を休みにします。レベルが上がると裏拍のカードが増えます。

レベル1の判定幅はPerfect ±75ms / Good ±150ms。レベルが上がるごとにGoodの幅が4msずつ縮まり、Perfectはその半分です。レベル10はPerfect ±57ms / Good ±114msです。

各レベルで満点の60％以上を取ると合格し、結果画面から次のレベルへ進めます。不合格なら同じレベルに再挑戦します。満点は順に1900・2200・2500・2800点、合格点は1140・1320・1500・1680点です。タイトルへ戻るとレベル1に戻ります。

レベル10合格後は、カード・紙吹雪などのお祝い演出とワルツが始まります。音量・ミュート設定を共有し、タイトルへ戻ると停止します。

## 構成と検証

- js/music-chart.js：使用中の音源の長さと拍の基準データ。
- js/difficulty.js：レベル別のカード配置と判定幅。
- js/game.js：音源読み込み、カウント、判定、画面更新、中断・再開。音楽と判定にAudioContext.currentTimeを使います。
- js/celebration.js：全レベル合格時の音楽と演出。
- index.html / style.css：画面構成と表示。
- assets/：ゲームで使う音源・画像・動画。

再生時に低域と中低域を補強します。画像・動画が読めないときは代替表示で続行できます。

`node js/verify.cjs` で検証できます。Node.js標準機能のみを使用します。実際のWAVの長さと譜面データの一致に加え、DOM・Web Audioのモックで読み込み失敗からの復帰、再生予約、キャッシュ、中断・再開、判定境界、重複入力、全10レベルの進行、フィナーレと後片付けを確認します。

実機での試聴・スマートフォンの操作感・出力遅延は自動検証の対象外です。
